# SVD 交互讲义

奇异值分解（SVD）的中文交互讲义：定义与结构、几何意义、2×3 手算、图像低秩近似、请假条语义分类、小结与自测，共六节、五个可动手的实验。

**在线阅读：** https://allecshi.github.io/svd-lecture/

- 单文件页面：`SVD交互讲义.html`，下载后双击即可离线阅读（首次需联网加载中文字体与数学字体）。
- 所有计算都在浏览器本地完成，没有服务端。
- 实验 05 的 8 维语义向量与词表是手工设定的教学示例，不是训练得到的模型。
